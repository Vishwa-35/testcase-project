User Guide - Test Case Manager

Learn how to use the Test Case Manager system

1 Getting Started

Welcome to the Test Case Manager! This system helps you manage and track test cases for your projects.

First Steps:
  • Navigate to the Test Cases page from the navigation menu
  • Use the filter sidebar to find specific test cases
  • Click on "Test it" button to execute a test case
2 Filtering Test Cases

Use the filter sidebar to narrow down test cases by various criteria:

  • Sheet: Filter by sheet name
  • SW Part Number: Filter by software part number
  • Application SW Version: Filter by version
  • Feature: Filter by feature name
  • Search: Search across all fields
Tip: Filters are applied automatically when you make a selection. Use the "Clear Filters" button to reset all filters.
3 Testing a Test Case

To execute a test case:

  1. Find the test case you want to test using filters
  2. Click the "Test it" button in the Actions column
  3. Fill in the required information:
    • Status (PASS/FAIL)
    • Reports (optional - can be a URL or text)
    • Comments (optional)
  4. Click "Save Execution" to save your results
4 Creating Test Cases

To create new test cases:

  • Click the "Create Testcase" button on the Test Cases page
  • Fill in all required fields
  • Or use the "Add New" button for quick addition
5 Exporting Data

Export test cases to Excel or view as HTML:

  • Click the "Export" button
  • Choose between Excel (.xlsx) or HTML format
  • Select the versions you want to export
  • Click "Export" to download or view
6 Viewing History

Track all activities in the system:

  • Navigate to "History" from the menu
  • View all changes, additions, and imports
  • See who made changes and when
7 Tips & Best Practices
  • Always fill in the status when testing (PASS/FAIL)
  • Add comments to explain any issues or observations
  • Use the search function to quickly find test cases
  • Export data regularly for backup purposes
  • Check the History page to track changes
